# Prompt-Injection Guardrail Benchmark

How often do prompt-injection detectors flag *legitimate* inputs a security researcher
asking how an attack works, an admin performing an action they're authorized to perform,
a user quoting an attack string to report it? This project measures that false-positive
rate for off-the-shelf guardrails and a small fine-tuned classifier, using the
[guardrail-hard-negatives](https://huggingface.co/datasets/3nesdeniz/guardrail-hard-negatives)
dataset (OWASP LLM01: Prompt Injection).

**Status:** Phase 1 scaffold. Results table below is filled in as detectors are run.

## Detectors compared

| Name | What it is | Runs where |
|---|---|---|
| `heuristic` | Regex keyword rules  the "WAF rule" floor | anywhere |
| `protectai` | ProtectAI `deberta-v3-base-prompt-injection-v2` | GPU/CPU |
| `promptguard2` | Meta Llama Prompt Guard 2 (86M)  gated, accept license first | GPU/CPU |
| `llamaguard3` | Llama Guard 3 1B via Ollama  a *content-safety* model, included to show safety ≠ injection detection | local Ollama |
| `qwen3-zeroshot` | Qwen3 4B asked to classify, via Ollama  the "just ask an LLM" baseline | local Ollama |
| `finetuned` | DeBERTa-v3-small fine-tuned on the train split (`train/finetune.py`) | Colab T4 |

## Quick start

```bash
python -m venv .venv && .venv\Scripts\activate       # Windows
pip install -r requirements.txt
huggingface-cli login                                 # for Prompt Guard 2 + pushing models

python -m data.load                                   # pulls dataset, writes data/*.jsonl + data/profile.md
python -m eval.run --predictor heuristic protectai    # baselines
python -m eval.run --predictor llamaguard3 qwen3-zeroshot --verbose   # needs `ollama pull llama-guard3:1b qwen3:4b`
python -m eval.report                                 # results/table__test.md + chart
python -m eval.errors results/*__test.json            # per-detector error dumps for the write-up
```

Fine-tuning: open `train/finetune_colab.ipynb` in Google Colab (T4), or run
`python -m train.finetune` on a GPU.

Offline smoke test (no downloads): `python -m eval.run --predictor heuristic --data data/sample_preview.jsonl`

## Metrics
----
Besides accuracy/precision/recall/F1 the harness reports:

- **FPR**  false-positive rate over all benign rows
- **FPR (hard)**  false-positive rate over benign rows designed to *look like* attacks. This is the number the project is about.
- **recall by attack family** and **FPR by benign technique** — which inputs each detector gets wrong
----

## Limitations

- The dataset is **synthetic** (template-expanded). Numbers show relative behavior between
  detectors on this stress test, not real-world rates.
- English only in v1; the dataset's Turkish families are dropped by `data/load.py` (use `--all-languages`).
- Small test split (≈150 English rows): differences of a few points are within noise.
- The author's own harness, [InjectBench](https://github.com/3nesdeniz/injectbench), can cross-check these numbers.
